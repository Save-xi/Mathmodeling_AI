# 面向高水平国赛作品的质量复核

用于赛前准备、完整方案的实质复核，或明确的“国一/冲奖”目标。单段润色、指定代码小修仍按原范围完成；不因奖项目标创建完整项目或自动查前沿论文。

**依据与解释分开。** 国赛章程的质量维度及按赛题制定评阅细则的要求见 [章程](https://www.mcm.edu.cn/html_cn/block/44e92058f537729c6b6a62a3662ee417.html) 与 [全国奖项评阅规范](https://www.mcm.edu.cn/html_cn/node/b1f48689659f0660e80a2d6279d7b37d.html)。以下是本地工作法，不是官方分值、获奖概率或“国一认证”。作品质量、自动结构检查和最终评奖是不同判断。

## 先形成完整答案，再补强有价值的认识

复用 `problem_map.md`、`model_contract.md`、结果证据表和 `qa_report.md`，不另建一套流水账。逐问核对“题面要求的实际交付物 → 带单位/条件的答案 → 核验方法 → 文件/论文位置”。若题目要求结果表、布局、操作方案、解释或比较，仅有模型公式、算法名称或一个目标值不算答完。

| 复核维度 | 要追问的证据 |
|---|---|
| 题意与完整性 | 所有子要求、指定条件和结果文件是否覆盖；跨问共享参数是否来自同一有效版本 |
| 模型依据 | 关键简化改变了什么；数据是否支持参数辨识；有无更合理、会改变结论的替代解释 |
| 数学内容 | 最关键的建模关系如何从定义/机制得到；适用域、边界、近似和最优性条件是否成立 |
| 结果可信度 | 独立重算、可行性、合适的验证和误差来源，是否真正支撑所报告的最终决策/数值 |
| 可解释贡献 | 能否解释某个阈值、取舍、失效条件或稳健规律，而不只是列出一串最优数字 |
| 可读与可复现 | 读者能否迅速找到每问答案、核心推导及验证；实际使用的代码/环境/输入是否齐全 |

每项写“已有证据 / 缺证据 / 存在冲突 / 不适用及理由”，引用具体位置。缺一问、违反硬约束或关键推导错误，不能靠其他项表现抵消。不要编造统一权重、分数线或依据文件齐全给出获奖保证。

## 把数学工作放在关键处

- 选决定主要结论的关系，说明它是题设、引用的定理/模型、自己的推导还是经验拟合；解释变量、条件和近似为何适用。无需重写所有教材公式。
- 针对争议假设检验其后果：如独立性、平稳性、几何近似、线性成本、循环终止条件。优先检验会改变结论的假设，而不是机械把所有参数扰动 10%。
- 在有效定义域内构造手算例、极限/守恒检查、解析界或另一种独立重算。两种算法求得相近结果，最多支持该数学问题的求解一致性；若共享同一错误建模关系，不能据此证明真实问题建模正确。
- 区分原问题与代理：连续松弛、加罚问题、离散网格、局部极值和仿真最优都要说明与原任务的关系。舍入、裁剪、修复和重新排程后，重新计算最终对象的全部硬约束与指标，不能沿用处理前分数。
- 用与任务相称的确定性边界、概率区间或场景结果。有限样本/网格验证不是“所有情况”保证；最大、最小、首次、必然等量词需要对应的论证。

建模应回到原问题检验假设和结果；[GAIMME 第二版的本科章节及附录 D](https://www.siam.org/media/n2tinywa/gaimme-2nd-ed-final-download-print-bw.pdf) 提供这种迭代建模和形成性提问的方法背景。这里不采用其教育评分量表作为国赛标准。

## 有预算地补强一个主要贡献

基线正确后，在现有合同中只列最值得补的几项：“缺口 → 会影响什么结论 → 最短补证方法 → 时间/算力 → 产物”。按结论重要性、失败风险和补证成本排序，不按算法新旧排序。

优先考虑由本题决定的参数阈值、决策稳定区间、可行/不可行边界、机制解释、合理的模型简化、误差对决策的影响或同条件比较。这些可以来自已有模型，无需换算法。把修错称为修错，不能包装为原创方法。

一次只投入一个有依据、可在冻结点前完成的主要补强。先定义检验与拒绝条件，再做实验；无收益或证据不足则保留基线。若各问已完整、关键证据充分、剩余缺口价值低，结束模型扩展，转入论文与交付。若确实需要新研究方法，再按 innovation-routing 交接；“目标国一”本身不是理由。

## 从读者和反驳者两种视角检查

先只读摘要、各问答案和核心表图，检查任务、结果、条件及主要证据能否被找到；这是本地可读性检查，不声称评委只看摘要或有固定阅读分钟数。再回到原题与核心推导，主动寻找一个能推翻最强结论的合法反例；发现后修正模型或收窄结论。

有独立复核条件时，让复核者先看原题、模型、代码和结果，再形成判断，避免先给“我们已通过”的结论。全国奖项评阅规范第十三条规定本科组全国一等奖申报论文由至少三位评委独立评阅；这里借鉴的是独立判断原则，不是要求每次任务调用三个 Agent。多个视角在同一上下文中自查不等于多个独立评委。

对核心方法准备简短解释：为何这样建模、关键参数从何而来、改变一个条件会怎样、如何从入口复现关键结果。由实际队员完成的理解与核验才可记作队员人工核验；AI 自查或另一个 Agent 的复核不能冒充它。可继续完成技术检查并列明尚待队员核验的项目，不据此反复请求实施许可。正式答辩的范围与方式按适用的全国及赛区要求，不假定所有队伍都有相同答辩，也不自动生成 PPT。

## 公开论文如何使用

只抽取表达、问题覆盖、推导与结果组织的可迁移做法，不复制算法、结论、数值或长句。例如 [2023 B226 官方展示](https://dxs.moe.gov.cn/zx/a/hd_sxjm_sxjmlw_2023qgdxssxjmjslwzs_2023btlw/231104/1865116.shtml) 的逐问摘要及结果文件对应关系可供结构观察；展示身份不证明其每个推导或验证都正确。抽样读过哪些页、是否拿到附件、是否实际复算，分别说明。涉及中文表达时交给 guosai-paper，不复制语料库进本 Skill。
