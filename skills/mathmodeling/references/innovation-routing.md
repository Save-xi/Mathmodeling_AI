# 创新方法路由

用于赛前算法/文献准备、赛时锚点匹配和需要研究方法的实质缺口。先复用经典路线及 `$mathmodeling-frontier` 的已核验锚点；离线匹配与联机研究是不同动作。普通补引用、时序、图、PDE 或控制关键词不触发宽范围研究。

## 先在赛前完成锚定

由 `$mathmodeling-frontier` 维护唯一 `references/precontest-anchors.md` 与 `algorithm-anchors.json`，按任务结构、独立数据规模、信息时点、硬约束和输出目标组织。赛前即使没有本届原题，也应完成有来源的条件候选、最小可检验增量、失败边界和实现状态；不能只回复“等赛题出来再搜索”。资料可标 `PREPARED`，不能预填本题验证。

赛时先离线选中相关卡，映射真实题目与基线，只查未覆盖机制/条件、新版本问题、重要负面证据和遗漏竞争路线。查询预算按 competition-budget；无缺口且不作当下最新声明可以零检索。卡片不匹配时修正路线，不把题意硬套进锚点。若 specialist 不可用，则使用已有项目的有日期锚点或经典路线；仅为必要缺口作有界检索。

## 进入、采用与停止是三件事

赛前研究请求应得到实际文献与条件候选；缺少具体赛题不妨碍知识准备。真实项目的原题、附件、baseline 或资源边界缺失时，其 task contract 标 `PROVISIONAL`，不能将家族锚点直接升为本题主模型。

采用顺序：问题事实 → 数学结构 → 可复现 baseline → 稳定缺陷 → 最小增强 → 同协议比较/消融 → 保留或回退。优先级为 correctness > problem fit > validation > interpretability > innovation。

baseline 满足任务的质量与验证标准、且没有值得补强的已知缺口时，停止模型升级。明确的高奖项目标可先做一次有预算的质量复核，但不自动启动前沿研究。无法完成公平比较、无法支持复杂度、增益低于预设实际阈值或复验波动、关键依赖/资源未知、或无法在保留的验证与论文时间内完成时，回退。完整比赛的预算与冻结点只在 [competition-budget.md](competition-budget.md) 定义；不要另开无截止时间的研究流程。

## 缺陷与可检验的增强

| 缺陷 | 可考虑的方向 | 采用前必须证明 |
|---|---|---|
| 机理存在系统性残差 | 小型残差修正、约束校准 | 残差可学习、守恒不被破坏、未见工况有收益 |
| 点预测不足以支持风险决策 | 校准区间/相关情景与稳健决策 | 覆盖、宽度、尾部损失和实际决策效果；边际区间不能代表路径保证 |
| 固定关系遗漏动态作用 | 有来源的动态关系模型 | 相对无图/固定图有独立增益，边不读取未来 |
| 干预效果不明确 | 合适的识别设计或效应界 | 处理、结果、时间、混杂、重叠、干扰假设成立；不能用预测拟合替代识别 |
| 重复数值求解昂贵 | 分解、低维代理或算子适配 | 训练/数据生成成本可摊销，最终输出可由原模型复核 |
| 需要可解释规律 | 受量纲/复杂度限制的符号发现 | 未见工况、噪声稳定、单位与极限一致；经验式不是已发现物理定律 |
| 多步反馈超出静态决策 | DP/MPC 或有条件的学习策略 | 可信转移/模拟器或离线覆盖、独立可行性检查和同预算增益 |

优先修正问题表达、约束、分解或信息时点。修复错误首先属于正确性，不自动构成方法创新。不得先选算法再编造 baseline 缺陷，也不把动物换名、调参或调用 LLM 包装成结构创新。

## 单一 frontier 交接契约

主 Skill 负责问题契约、实施、验证与论文 claim level；`$mathmodeling-frontier` 负责赛前方法锚点、对应一手文献、evidence IDs、版本差分和必要的候选排名。不要维护第二份目录或评分。

交接只需一份记录：

1. `problem_contract_status`、实际输出、数据独立单位/时间跨度、机制与信息时点；
2. `baseline_id`、可运行 baseline、具体失败切片/指标与复现方式；
3. 公平协议：同信息、划分/场景、指标、约束、种子策略和总计算预算；
4. 硬件/显存、系统、许可证、依赖、权重可用性，原型与训练/调试时限；
5. 一个明确 `delta`、消融计划、实际收益阈值、拒绝条件和可执行回退。

只消费带时间戳、去重 `evidence_ids`、来源状态、可行性与资源状态的候选。未知不能默认为通过；资源/契约/可行性未知的方案至多 `WATCH`。`PRIMARY` 只是实验前候选，不是本题已有效；本地公平实验后才裁决保留或回退。论文是否录用与在本题是否可用分别判断。

历史 `frontier-modeling-2026.md` 仅为兼容归档，当前从 specialist 的锚点目录进入；缺口查询保留原记录及真实新增日期，不将复用伪装为今天已重新检索。文献支持不等于本地实验支持；核验失败标明边界，不补写题名、引用、性能或代码地址。

## 候选与资源筛选

通常只比较 baseline 与一个最小增强；必要时再保留一个替代候选。Conservative/Balanced/Aggressive 只在用户需要风险比较时列出，不是必须实现的三条路线，也没有 Balanced 默认胜出。

候选标签可简写为任务、独立数据规模、结构、解释性、总时间、峰值内存、代码/权重/许可证和未知项。当前证据最充分、可按时交付的方案优先。RTX 4060 8GB 等单卡任务先测真实输入下的小样本峰值内存和端到端时间；不能由参数量或 GitHub 存在推断已适配。检查 Windows/WSL/Linux 和 CUDA 依赖；环境安装超原型预算即回退。

从零预训练大型算子/基础模型、临场搭多智能体 RL、单静态实例训练求解策略、无必要的动态/异构图通常排除。现成权重也必须匹配任务、接口和预算。昂贵代理或学习求解器需报告训练加求解总成本和 break-even 实例数，不能只报推理加速。

## 组合与消融

组合必须说明各模块输入输出、缺陷对应关系、单位、信息时点、训练/求解顺序、目标/约束和失败回退。默认只增加一个主要模块。

`A` 对 `A+B` 检查新增模块的条件增益。`A`、`A+B`、`A+B+C` 只支持该顺序下的逐步增益；若主张 B/C 各自独立有效或有协同，还需 `A+C` 等匹配对照。预算不足时收窄主张，不把未做消融写成已证实。普通集成不自动算创新。

## 论文主张分级

| Level | 本题贡献 | 允许措辞 |
|---|---|---|
| 0 | 采用现成方法 | 采用、应用 |
| 1 | 调参、优化器或初始化比较 | 调整、比较；不称结构创新 |
| 2 | 有题目依据的损失/约束/特征/流程适配 | 针对……适配；给出改动与验证 |
| 3 | 缺陷驱动的结构组合且有匹配消融 | 构建/集成……以处理……；不自动声称原创算法 |
| 4 | 有归属清晰的理论/算法贡献 | 仅在推导、证明或充分比较支持时声称；竞赛少见 |

新论文模型的直接使用通常仍是 Level 0。LLM 用于检索、写码和审计是工具使用；只有其输出进入数学模型且有独立增量验证时才算模型组件，其版本、随机性、失败和成本仍需说明。

输出保持紧凑：baseline/缺陷 → 选定 delta 与来源 → 公平协议/预算/拒绝条件 → 实际实验结果 → 保留或回退 → 可写入论文的证据边界。未执行的候选只进入计划或展望，不进入摘要的完成贡献。
