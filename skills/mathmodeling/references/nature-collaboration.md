# Optional specialist collaboration

`mathmodeling` owns question order, modeling judgment, canonical evidence and contest delivery. Use a specialist only for a relevant bounded subtask; inspect its actual language, source scope and output requirements before handing off. Installed does not mean appropriate, and a skill handoff is not an instruction to spawn another agent automatically.

| Need | Appropriate route |
|---|---|
| Chinese CUMCM prose | Use the installed `$guosai-paper` when relevant, or this skill's evidence-grounded Chinese writing rules. Preserve formulas, values, question order and claim limits. |
| General modeling references | Search authoritative original papers, books, official proceedings and software documentation without a journal-family whitelist; an installed `$nature-academic-search` may help a genuinely multi-source task. |
| Reference metadata verification | `$nature-ref-verifier` for actual title/author/year/DOI conflicts. Do not turn unavailable access into fabricated metadata. |
| Explicit Nature/CNS-only citation request | `$nature-citation` only when its strict publisher-family restriction matches the user's requested scope; it is not the default for OR, statistics or numerical-method references. |
| Scientific figures | `$nature-figure` for complex figure work; pass the existing Python/R workflow and contest output needs. Do not import unrelated journal-production requirements or AI image generation into ordinary numerical plots. |
| Statistical reporting | `$nature-statistics` for independent units, effect sizes, intervals, assumptions and significance wording; a reporting review does not establish validity of raw analyses. |
| English paper or requested translation | `$nature-polishing` for English/zh-to-en work. Do not route Chinese-preserving contest polishing through its English language axis. |
| Explicit paper presentation | `$nature-paper2ppt` only when a PPTX is requested; no presentation artifacts for a paper-only task. |

Use only available relevant capabilities and preserve the contest deadline. Pass the bounded question, language, canonical sources/results, exact output and remaining budget. Do not invoke `$nature-writing` as the primary contest-paper skeleton, impose journal-specific gates on a contest, or broaden a narrow edit into a new research project. If a specialist is unavailable or mismatched, complete the in-scope task directly.
