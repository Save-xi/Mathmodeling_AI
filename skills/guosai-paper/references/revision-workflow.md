# 局部润色、压缩与验收

先按用户要求确定深度：字词修订、句序压缩、段落重组，或有证据支持的实质改写。已授权润色即可完成必要修改；发现原稿不受支持的主张时，给出有边界的正文并列明变化，不新增逐句审批。

## 最小材料与保留项

局部修辞任务以原段落和已给背景为输入即可。全文重构或新增结果解释才需要相应题面、章节、数据/结果依据。未提供附件时，不声称独立核验，也不以此拒绝能完成的表达修订。

在草稿旁记住或短列：对象—指标—数值/单位—条件—来源。不是只记一串数字。另保留公式、不等式、概率事件、时间与样本范围、否定、约束方向、图表/引用/文件命名及求解状态。不同稿本冲突时保留待核项，不能凭“更顺”自行裁决。

范围与逻辑方向需要单独核对：“区间内/区间外”“给定样本/总体”“至少/至多”“存在/任意”“充分/必要/充要”不能互换。指代不够明确时重复具体范围，宁可写“区间外”也不改成可能回指所测区间的“整个区间”。证明增加条件后成立，只给出该条件下的成立结论；没有逆向证明，不能写成“成立所需条件”或暗示该条件必要。

## 让段落更有用

先问读者读完本段应得到哪个判断。保留支持它的最短证据链；有必要时再补条件、解释、对下一问的影响或失效范围。段落任务可分别是：提出难点、界定对象、完成推导、报告结果、比较取舍、说明局限。不要每段强塞结果、机制和限制三句话。

- 开头已经给出明确判断时，不再用段尾同义总结重复。
- 表格完整列出结果，正文挑决定性变化和例外，不逐格口述。
- 机制有推导/实验依据时解释“为何”；仅有观察时写规律，并把候选解释标为推测，避免编造因果链。
- 问间承接写“保留什么、改变什么、因此补什么”，不重复前问完整方法。
- 常规事实直接写；“可能、一定程度上、较为、具有一定”没有不确定性依据时也会冲淡有效结论。
- 不因替换连接词而拆坏条件与结论的对应，不用长句/短句比例作为质量指标。

## 定量表达核对

| 表达 | 必须核对 |
|---|---|
| 相对降幅 | (旧值−新值)/旧值；旧值为零、变号或指标可为负时不能套用普通比例解释 |
| 百分点变化 | 两个百分数直接相减；不同于相对百分比变化 |
| 改善 | 指标方向、比较对象、同一口径与主要代价；不能只给最好的一项 |
| 显著 | 统计显著性与实际意义分开；没有统计检验不能把一个差值写成统计显著 |
| 稳定/稳健 | 给出实际扰动因素、范围、评价量与结果；局部敏感性不覆盖所有分布/场景 |
| 最优 | 区分问题的最优解、算法求到的可行解及已证最优；时间终止或非零 gap 不能被改写成最优证书 |
| 预测/因果 | 预测准确、相关显著或时间先后都不能单独支持干预效果 |

以下均是合成教学例子，数值不能迁入正式论文：

1. **有差值、无显著性检验**  
   原写：“MAPE 从 12.4% 降到 9.8%，说明模型显著优于基线。”  
   可改：“在同一留出集上，MAPE 由 12.4% 降至 9.8%。”如压缩比较需要，可核算为下降 2.6 个百分点；相对降幅约 20.97%，不能写成下降 2.6%。是否有统计显著性另行说明，不写进未执行结果。
2. **求解状态限制**  
   原写：“达到时限，返回可行解，gap 为 3.1%，得到全局最优。”  
   可改：“在时限内得到可行方案，最优性间隙为 3.1%。”保留目标值与已给条件；不自行补 gap 定义或最佳界。
3. **保留取舍**  
   若误差下降但时间由 3.2 s 增至 8.1 s，正文应保留这一代价。没有优化性能指标支持时，不概括为“整体性能全面提升”。
4. **局部稳定性**  
   只测参数 ±5%、结果最大变化 1.8%，可写所测范围内的变化；不用“所有工况均可靠”，也不无端削弱成“似乎有一点效果”。
5. **定性答案**  
   若任务是给出反例与成立条件，摘要写明否定了哪个命题、在何种条件下成立；不为凑定量模板虚构准确率。

## 改写后如何验收

对齐原稿与改稿的对应段落，检查任务回答是否保留、指代是否唯一、数字/单位与对象是否绑定、条件/否定/方向是否相同、引用位置是否仍支撑该句。必要修正强度或删除推测时，在随附说明中点明，不悄然把实质变化说成“仅改措辞”。

有两个对应文本文件时，可运行 ../scripts/check_revision.py。只比较正文片段，不把“修改说明”混入改稿。其计数比较不能验证语义：把 A=3、B=5 换成 A=5、B=3 仍可能零差异。量纲换算、派生数值、公式等价、引用搬移和重复删除均由人裁决；它不重写文件，也不作为数学通过证书。

完成一轮实质修订、一轮事实/语义对照后，若句意清楚、证据范围准确且满足长度要求，就交付。还存在证据缺口时只列必要待核项，不用反复替换同义词掩盖。
