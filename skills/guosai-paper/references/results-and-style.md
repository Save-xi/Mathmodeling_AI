# 结果叙述与语言校准

## 事件与过程

按实际需要选用：

1. 初始状态或适用场景；
2. 触发条件或变量变化；
3. 可解释机制；
4. 可观察结果；
5. 建模映射；
6. 适用边界。

“随后”只表示先后；“因此、从而”需要可追溯前提。只有相关、拟合或时间顺序证据时，使用“观察到关联/变化”，不写因果效应。

## 逻辑关系迷你表

| 关系 | 可用结构 | 必须同时给出 |
|---|---|---|
| 条件/因果 | “在 `[条件]` 下……”；“由于 `[可追溯原因]`，因此……” | 条件或前提，不能用连接词代替证据 |
| 推导/承接 | “由式 `[X]` 并结合 `[定义/约束]` 可得……”；“在问题 `[i]` 的结果基础上……” | 式号与新增信息，或继承项与变更项 |
| 比较/转折 | “在相同 `[协议]` 下，与 `[基线]` 相比……”；“尽管 `[现象]`，但在 `[边界]` 内……” | 同协议数值，或转折成立的范围 |
| 边界 | “该结果仅支持 `[主张]`，不能推出 `[更强主张]`” | 数据、识别或外推限制 |

## 图表与数值

按本段任务选择主张、证据、解释、意义或边界，不把它们固定成每段五句话：

- 先说图表回答什么；
- 给出图表编号、条件、关键量、趋势、拐点、极值或异常；
- 用模型机制解释；
- 说明对决策或下一问的意义；
- 交代失败区间或不能推出的内容。

可填结构：

- “图 `[X]` 显示，在 `[条件]` 下，`[指标]` 随 `[变量]` 由 `[a]` 变至 `[b]`；变化在 `[区间]` 最明显。”
- “在相同 `[划分/场景]` 下，与 `[基线]` 相比，`[指标]` 由 `[a]` 变为 `[b]`，同时 `[成本/风险]` 变化 `[c]`。”
- “该约束对应题面中的 `[限制]`：当 `[条件]` 成立时，`[变量关系]` 必须满足 `[含义]`。”

数字的单位、口径和条件须能在句内或清楚的上下文定位，不必在每句重复。不要复述表中所有数字。相对百分比与百分点、增益与代价、区间估计与误差必须分开；细则与改写对照见 [revision-workflow.md](revision-workflow.md)。

## 检验、敏感性与稳健性

按“扰动/对照—评价指标—结果—稳定范围—失败情形”写：

- “将 `[参数]` 扰动 `[范围]` 后，`[指标]` 变化 `[区间]`，支持模型在所测范围内对 `[因素]` 较稳定。”
- “该检验支持 `[具体主张]`，但不能说明 `[更强主张]`，因为 `[数据/识别限制]`。”

拟合、数值一致性、外推、鲁棒性和因果识别是不同证据。另一算法给出近似结果只能作交叉校验，不能自动证明真实正确。

## 方法角色与创新动词

- `采用/应用`：使用现有方法；
- `适配`：为本题改变输入、约束、损失或流程；
- `集成`：连接模块并写清数据流，强主张需模块消融；
- `改进`：需要命名基线、相同协议、指标与不确定性；
- `引入`：把现有组件带入方案，不表示原创；
- `提出`：只用于清楚归属于本工作的构造。

方法并列时写角色：“用 A 估计参数，以 B 搜索方案，再用 C 独立复核”，不写算法名串联。

## 常见空泛表达

| 空泛写法 | 可核验改写 |
|---|---|
| 模型显著提高准确性 | 给出相同划分、基线、指标、数值变化与不确定性 |
| 验证了模型的科学性 | 写明检验、误差、支持的主张和适用范围 |
| 由图可知效果很好 | 指出图号、条件、趋势、拐点、异常和比较对象 |
| 采用多种算法 | 说明每种方法负责的环节 |
| 推广性很强 | 写明可迁移结构、需重估参数与失效条件 |
| 因此存在因果关系 | 若无识别设计，降格为关联或预测关系 |

## 语体与节奏

- 段内主语稳定：“本文”用于论文动作；“模型/结果/图表”用于客观证据。
- 一句优先一个主要动作；条件多时先界定条件，再写方法和结果。
- 连续三个以上顺序词时检查能否改为目的、承接、比较或因果。
- 段首先定位判断；只有增加信息时才补段尾解释/边界，不首尾重复方法名，也不把所有段落改成同一种节奏。
- 一个对象使用一个主称谓；代词必须明确回指。
- 删除“值得注意的是、显而易见、效果非常好”等无信息表达。

需要观察真实语料中的短用法时，转到 [corpus-examples.md](corpus-examples.md)，并回查原文件；频率和获奖身份都不替代证据审校。
