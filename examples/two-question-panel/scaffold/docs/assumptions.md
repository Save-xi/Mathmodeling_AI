# 事实、推断、假设、提案与未知项

## FACT（原题/附件/已执行结果）

- 待补：陈述、来源锚点、单位和适用条件。

## INFERENCE（从明确前提得到的推断）

- 待补：推理、假设、范围及验证方式。

## ASSUMPTION（为可辨识或可求解而引入）

- 待补：假设、影响和验证/敏感性测试。

## PROPOSAL（尚未实现）

- 待补：候选方法及采用条件。

## UNKNOWN（缺失或不可辨识的信息）

- 待补：未知内容、对结论的影响、解决方式或结论边界。

另记 not_implemented / implemented / executed / verified 进度；源文件陈述可直接标 unverified / verified。执行过不等于独立核验。
